Translation WordSwipe

Privacy Policy / 隐私政策

1. 概述与核心原则

Translation WordSwipe（以下简称“本软件”）是一款专注于 Windows 平台的高性能划词翻译工具。我们高度尊重并严格保护用户的隐私。本软件不会收集、上传、分析或出售用户的任何个人身份数据或日常使用习惯。

核心承诺：无用户追踪、无广告推送、无第三方统计 SDK、无远程控制后台。

2. 数据处理与传输

  • 划词与选中文本处理：当您在屏幕上划选文本并触发翻译时，被选中的文本会通过内存传递至翻译模块，并仅用于向您选择的翻译引擎发起即时请求。文本内容绝不会保存到任何持久化日志中。
  • 剪贴板访问：为了跨应用程序捕获选中的文本，软件会在瞬间读取选中文本并立即恢复您的历史剪贴板内容。本软件绝不会监控或存储您复制的其他无关内容（如密码、银行账号等）。
  • 网络通信：软件发起的网络请求仅直接发送至公开可用的翻译服务接口（包括 Google 翻译、必应翻译或您自行配置的自定义代理/API）。我们不设立任何收集用户文本的中间分析服务器。

3. 本地存储

本软件的所有配置（例如语言方向、界面布局、代理服务器设置、开机自启等）均完整保存在您本机的 %APPDATA%\TranslationWordSwipe\settings.json 文件中。该配置文件完全归您所有，卸载软件或清空该目录即可彻底移除所有配置。

4. 权限使用说明

  • 全局输入钩子 (Low-Level Mouse Hook)：用于监听划词滑动手势，以便判断用户是否在屏幕上完成划词。
  • 开机自启动：仅在您主动开启自启开关时在注册表或 Windows 启动项中写入启动路径，您可随时在设置中关闭。

5. 隐私政策的变更与联系

如本隐私政策有任何重大修改，我们将通过 GitHub 仓库发布最新版本。若您对本政策有任何疑问，欢迎通过 GitHub Issues 与我们联系。

1. Overview & Core Principles

Translation WordSwipe ("the Application") is a high-performance desktop text-swipe translation tool for Windows. We take your privacy very seriously. The Application does not collect, harvest, analyze, or sell any personal data, identity information, or browsing history.

Our Commitment: Zero tracking, zero telemetry, zero advertising SDKs, and zero centralized backend servers.

2. Data Processing & Network Transmission

  • Selected Text: When you select text on screen to trigger translation, the selected text is temporarily handled in memory and directly forwarded to your chosen translation engine (e.g., Google Translate, Bing Translator, or your custom API endpoint) solely to deliver the translated result. It is never logged or cached permanently.
  • Clipboard Usage: To reliably capture text across various desktop applications, the Application briefly inspects the selected text and immediately restores your previous clipboard history. We never inspect or retain unrelated clipboard contents.
  • Network Requests: All network requests are dispatched directly from your device to the target translation APIs. There is no intermediate proxy or analytics server intercepting your queries.

3. Local Storage

All application configurations (such as translation preferences, layout options, and proxy settings) are stored locally on your machine at %APPDATA%\TranslationWordSwipe\settings.json. You have complete ownership of these files.

4. System Permissions

  • Low-Level Mouse Hook: Used solely to detect swipe/selection gestures to trigger translation on demand.
  • Autostart: Registered only when you explicitly enable the startup option in settings, and can be disabled anytime.

5. Contact & Updates

If you have any questions or feedback regarding this Privacy Policy, please open an issue on our GitHub repository.
